How this page is made

  1. A GitHub Action snapshots ~50 company career boards (Greenhouse, Lever) daily and lands the file in a Unity Catalog volume.
  2. A Lakeflow declarative pipeline loads it with Auto Loader (bronze), tracks each posting's first and last day (silver), and quarantines bad rows.
  3. ai_query extracts skills, years and domain from each new posting, exactly once; a deterministic scorer rates fit (gold).
  4. Metric views define every number here once; the same layer powers an AI/BI dashboard and a Genie Agent.
  5. A quality gate must pass before this page is republished.
